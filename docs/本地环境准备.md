# 本地生成环境准备（ComfyUI SparkH3）

选择本地后端时，把本文档发给用户。目标：一台 NVIDIA 显卡的机器跑通 ComfyUI + H3（MiniMax H3）人物替换出图，1920×1088 原生直出。

## 1. 硬件要求

| 项 | 要求 | 说明 |
|---|---|---|
| 显卡 | **RTX 4090 / 24G 显存**（实测基准） | Spark-H3 块稀疏注意力按 SM89（40 系）优化；同代 24G 卡（4090D/4080Ti 类）可用，A 卡/N 卡旧架构不走 Spark 加速会显著变慢 |
| 内存/硬盘 | 32G 内存建议；模型合计约 100G+ | 模型不占整合包磁盘，可用 `extra_model_paths.yaml` 挂到大盘 |
| 压力实测 | 141 帧＋双图参考＋视频参考 @2MP（1920×1088）约 5 分钟/段、无 OOM | 全项目 40 段约 2 小时跑完；显存吃紧就降 `--mp`（如 1.0 ≈ 1344×752） |

## 2. 下载整合包及模型（网盘）

**整合包及模型下载：https://pan.quark.cn/s/54d2b9913687**

包内包含：

- **ComfyUI v0.40.0 + Spark-H3 v0.1.4 加速包**（含 `运行comfyui - SparkH3.bat` 启动器、`h3-api/` 提交脚本与 Spark 版模板、int8 视频 VAE）
- **H3 模型文件**：77G bf16 主模型 + ref2v_turbo_4step LoRA + 文本编码器 + int8 主模型（经 `extra_model_paths.yaml` 关联，可挂到其他盘）

下载后解压到约定位置（默认 `D:\ComfyUI_SparkH3\`；放别处就设环境变量 `H3_API_DIR` 指到其中的 `h3-api` 目录）。

## 3. 软件条件

- **Python 3.10+**（系统 Python 即可）＋ `pip install requests`
- **ffprobe**（提交脚本用来自动数视频帧）：用项目里的 `ffmpeg/` 便携版即可，脚本会自动优先使用
- Windows 10/11；Linux/Mac 需自行对应启动命令

## 4. 启动与自检

1. 双击 `运行comfyui - SparkH3.bat`，等到 `http://127.0.0.1:30001` 可访问（约半分钟）。启动参数已内置 `--reserve-vram 3.5 --vram-headroom 1 --fast fp16_accumulation`，并把输入/输出目录重定向到共享目录。
2. 提交一条干跑确认接线（不实际出图）：

```bash
python scripts/h3_batch.py print 001
```

能打印"干跑 OK: 原生 1920x1088 (无超分) | 帧长 …"即链路通。
3. （可选）验证 Spark 加速生效：ComfyUI 控制台日志出现 `[Spark-H3] active on SM89 (N tokens)` 且 `unexpected_fallbacks=[]`。

## 5. 常见问题

| 现象 | 处理 |
|---|---|
| 提交失败带 node_errors | 多为模型文件缺件——核对网盘包是否解压完整、`extra_model_paths.yaml` 路径是否有效 |
| OOM / 进程被杀 | 降 `--mp`（`python scripts/h3_batch.py --mp 1.0 submit …`）；更长片段分段接龙（每段 ≤10s，后段以前段尾帧为首帧参考） |
| 连不上 30001 | bat 没启动成功，看窗口报错；端口被占就改 bat 里的 `--port` 并用 `--port` 参数同步提交脚本 |
| 输出找不到 | 在 ComfyUI 输出目录 `apt复刻/` 下；脚本经 API 自动取回，不依赖本地路径 |
