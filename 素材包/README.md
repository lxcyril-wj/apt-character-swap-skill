# 素材包说明

本目录提供复刻所需的**方法性素材**（可安全开源的部分）：

| 内容 | 说明 |
|---|---|
| `分段简介/001.txt … 044.txt` | 前 44 段的逐段中文内容简介（写提示词的内容基准），源自 wuwukasi 复刻包 |
| `原始帧数.txt` | 组装时每段保留的帧数（前 44 段合计 2316 帧） |
| `补齐后帧数.txt` | 每段用来生成的帧数（17n+5）＋出镜角色对照 |
| `替换用参考图/` | 示例参考图（一号/二号）；换成你自己的角色时直接替换文件名不变 |

## ⚠️ 版权提示

原 MV 的**分段视频与音轨不在本仓库分发**（音乐与画面版权归原权利方）。两种获取方式：

1. **网盘完整版（推荐）**：整合包及模型＋带参考 MV/音频素材的完整复刻包，都在同一个网盘里：
   - 国内（夸克网盘）：https://pan.quark.cn/s/54d2b9913687
   - 海外（Google Drive）：https://drive.google.com/drive/folders/1SCBLNyaL85jXigVSioocU1NAKLc9VHFY?usp=sharing
2. **自备 MV 切段**：使用你自己持有的正版 MV，一条命令自动复现素材结构：

```bash
python tools/make_segments.py "你的MV文件.mp4"
```

脚本会按帧数表切出 44 段、末帧补齐到 17n+5、重计时 24fps，并抽取 `原片音轨.m4a`；每段帧数自动校验，不符会提示核对 MV 版本。

> 下载自网盘或自行切出的视频/音频素材仅供个人学习复刻使用，请勿二次公开传播。
